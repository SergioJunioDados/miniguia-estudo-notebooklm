# 📓 Miniguia de Estudos: Transição de Carreira para Dados com IA

## 🎯 Contexto e Objetivos
Desafio de projeto da **DIO**. O objetivo é utilizar o **Google NotebookLM** como uma ferramenta de aprendizagem com minhas experiências anteriores (Administrativo, Técnico e Bombeiro) se conectam com a carreira de **Analista de Dados em 2026**.

## 📚 Curadoria de Fontes
Utilizei 5 fontes estratégicas para alimentar a IA:
1. **Histórico Profissional:** Detalhamento de funções em Gestão Adm Sênior, Edificações e Hidráulica.
2. **Mercado de Dados 2026:** Definição da profissão como parceiro estratégico de negócios.
3. **Domínio de SQL:** Conceitos de extração de dados de sistemas corporativos.
4. **Python e IA Generativa:** Uso de automação, Data Cleaning e Copilotos de IA.
5. **Power BI e Visualização:** Criação de dashboards de KPIs e Data Storytelling.

## 🧠 Engenharia de Prompts e "Cicatrizes"
### Pergunta Estratégica Utilizada:
> "Com base nas 5 fontes que carreguei (meu histórico em Adm/Técnico/Bombeiro e as tecnologias de Dados), crie um Miniguia de Estudo Personalizado Contendo um Resumo de como minha experiência , me ajuda a ser um Analista de Dados em 2026 .criando um  Glossário de 5 termos que unem meu passado com meu futuro"

### 🩹 Minhas Cicatrizes (O que aprendi no processo):
*   **Ajuste de Contexto:** Rapaz eu tive algumas dificuldades em dar o prompt correto kk , ela me dava algumas resposta genericas e so entendia uma das 3 profissões no texto . lembrei de uma das aulas anteriores que a IA precisa do contexto completo para cruzar as informações e não dar respostas genéricas.
*   **Refinamento de Prompt:** Tive que ajustar o comando para que a IA entendesse que o diagnóstico que eu fazia como **Bombeiro Hidráulico** é puro raciocínio lógico de dados, o que gerou o insight sobre "Diagnóstico de Vazamento → Data Cleaning".

## 📖 Miniguia de Estudo (Entrega Final)

### 1. Resumo: Sua Experiência como Diferencial
Em 2026, o Analista de Dados é um parceiro estratégico. Minha transição une a **Visão de Negócio** (Adm Sênior), o **Planejamento Estruturado** (Técnico em Edificações) e a **Resolução de Problemas Complexos** (Bombeiro Hidráulico) para investigar padrões e tendências com IA.

### 2. Glossário de Integração (Passado ➡️ Futuro)
*   **Diagnóstico de Vazamento ➡️ Limpeza de Dados:** Identificar e corrigir falhas antes da análise.
*   **Levantamento de Quantitativos ➡️ Consultas SQL:** Extrair volumes específicos de dados estruturados.
*   **Fluxo de Caixa ➡️ Dashboards:** Transformar planilhas em painéis interativos de saúde financeira.
*   **Cronograma de Obra ➡️ Previsão de Tendências:** Usar lógica de etapas para antecipar o futuro do negócio.

### 3. Prompts Reutilizáveis para Estudo
*   **Prompt de Negócio:** "Sugira 5 KPIs essenciais para um Dashboard de Power BI focado em construção civil em 2026."
*   **Prompt de Ferramenta:** "Explique, usando uma analogia com diagnóstico hidráulico, como usar Python para tratar valores duplicados."
